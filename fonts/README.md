# خط DIN Next LT Arabic

ضعي ملفات الخط في هذا المجلد بالأسماء التالية بالضبط حتى يعمل الموقع:

| الوزن | اسم الملف المطلوب |
|-------|-------------------|
| Regular (عادي) | `DINNextLTArabic-Regular.woff2` و `DINNextLTArabic-Regular.woff` |
| Medium (متوسط) | `DINNextLTArabic-Medium.woff2` و `DINNextLTArabic-Medium.woff` |
| Bold (عريض) | `DINNextLTArabic-Bold.woff2` و `DINNextLTArabic-Bold.woff` |

## كيف أحوّل ملفات الخط إلى woff2؟

إذا عندك ملفات `.ttf` أو `.otf`، حوّليها مجاناً عبر:
- https://transfonter.org  (اختاري woff + woff2 ثم Convert)
- https://cloudconvert.com/ttf-to-woff2

## خطوات الرفع

1. أنشئي مجلد `fonts/` (موجود).
2. ارفعي ملفات الخط الستة بالأسماء أعلاه.
3. ادفعيها على GitHub (commit + push).
4. من لوحة التحكم ← القالب والألوان ← اختاري "DIN Next LT Arabic" ← حفظ.
